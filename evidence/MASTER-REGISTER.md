# CC-Test — Correctness Master Register

Consolidated register of the correctness track: every acceptance record with
**product · version · reference · criterion family · cases · result · security
verdict · validated date · evidence class**. Ground truth = [`index.json`](./index.json)
(machine-generated by `correctness/index_evidence.py`) plus each record's own
`manifest.json`. This file is the curated, human-readable companion to that
index — the correctness analog of `CESM-Sec-Track`'s master findings register.

> ⚠ **Only one record is filed (clubb-jax).** The rows under *Targeted* are
> declared intentions with reference evidence to backfill, not verified results.
> Do not read a targeted row as a PASS.

## Legend

**Criterion family** (from `schemas/acceptance.v1.json`)
- **bitwise** — byte-identical output between a reference run and a candidate run; suits a whole-model port (PyCAM5, freeCAM).
- **unit-differential** — per-unit gates (`unit_set_equal`, `ulp_tiered`, `nan_mask_equal`, confidence notaries) summarized in a `verification.json`; suits a kernel-level rewrite (clubb-jax, clm-ml-jax, elm-jax).
- **statistical** — a candidate lying within the ensemble spread that characterizes the model's own variability. **Provisional (decision D4): the verifier rejects evidence filed against it until the vocabulary is finalized.**

**Result** — **PASS** (every gating check passed) · **FAIL** (a gating check failed) · **ERROR** (nothing was compared — mismatched file sets, unreadable input, no files in scope). ERROR is not FAIL: "not compared" is kept distinct from "compared and identical."

**Security verdict** — **PASS** only when all scans ran and every finding count is zero · **NOT_RUN** (the cyber gate was not run for this commit) · **INCOMPLETE** (a scanner could not complete, e.g. a missing tool).

**Evidence class** — **complete** (the record stands on its own) · **reconstructed** (a format example, not compliance evidence).
